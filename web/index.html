Run the five-act demo

Phone on one screen, laptop on the other. Timings are compressed in demo mode.
  1. Missed callOn the phone page tap the call button. The callback rings a few seconds later.
  2. ReportAnswer. The assistant says it is an AI. Describe the fault, hear the read-back, say “ho” or “haan”.
  3. DashboardA red pin appears with the priority and the reason for it.
  4. EngineerAcknowledge, then report the fix. The pin turns haldi yellow.
  5. VerificationThe phone rings again. “Yes” verifies (green). “No” reopens at higher priority and the false-closure rate moves.
Independent prototype, not an official government service. No real complaint is sent to any authority. Built with AI assistance. API referenceEvaluation
