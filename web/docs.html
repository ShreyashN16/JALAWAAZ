API reference

OpenAPI JSON

All responses are JSON unless noted. Errors always have the shape {"error": {"code", "message", "request_id"}}, and every response carries an X-Request-ID header that also appears in the server log.

Staff endpoints need the session cookie from POST /api/login. Calls that change data also need the X-CSRF-Token header returned by login or GET /api/me. Public phone endpoints are rate limited per IP address.

The longer guide, with examples, is docs/API.md in the repository.
